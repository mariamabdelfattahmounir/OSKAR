# OSKAR MedStat — Production React Application

Canonical production frontend for OSKAR MedStat clinical protocol generation, study navigation, statistical engine, and cross-role audit platform.

## Supported Roles
- **Researcher** (`researcher.oskar@gmail.com`)
- **Reviewer** (`reviewer.oskar@gmail.com`)
- **Supervisor** (`supervisor.oskar@gmail.com`)
- **Institution** (`institution.oskar@gmail.com`)
- **Admin** (`admin.oskar@gmail.com`)

## Tech Stack
- React 18 + Vite
- Tailwind CSS v3/v4
- Material Symbols Outlined icons
- Custom OSKAR Design System (Light/Dark themes, English/Arabic i18n + LTR/RTL)

## Quick Start
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
npm run preview
```
